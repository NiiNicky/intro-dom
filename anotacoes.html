Conhecendo o DOM

O que é o DOM?

DOM significa Document Object Model .

É uma representação do documento HTML em forma de objetos, organizada em uma estrutura hieráquica de árvore conhecida como DOM tree.

Exemplo de DOM tree (árvore do DOM) - foto: Google

Note que cada elemento HTML está conectado. Chamados esses elementos do nó (node) dentro dessa estrutura.

Em outras palavras, o navegador basicamente transforma o HTML em uma estrutura que o JavaScript consegue acessar e manipular.

Para que serve o DOM?

O DOM permite que o JavaScript interaja com os elementos HTML. Exemplos:

  • Selecionar elementos: Encontrar botão
  • Alterar conteúdo: Alterar o texto de um paragrafo, titulo, etc
  • Alterar estilo: Altera a cor de um botão, tamanho da fonte, etc
  • Criar elementos: Cria novo paragrafo, botão, links, etc
  • Remover elementos: Remover paragrafo, botão, links, etc
  • Capturar eventos: dectectar cliques, teclas pressionadas, etc
  • Modificar atributos: Alterar um src, um arial-label, etc
